# 구현 계획

작성: 2026. 8. 5. 13:50 (구현 시작 전)

## 만들 순서

한 번에 하나씩, 동작하면 바로 커밋한다.

| 순서 | 기능 | 확인 방법 |
|---|---|---|
| 1 | 화면 뼈대 (입력 폼 + 목록 영역) | 브라우저에서 폼이 보인다 |
| 2 | 활동 등록 → localStorage 저장 | 새로고침해도 데이터가 남는다 |
| 3 | 활동 목록 조회 (최신순) | 등록 순서 반대로 표시된다 |
| 4 | 빈 목록 안내 문구 | 데이터가 없을 때 안내가 뜬다 |
| 5 | 활동 삭제 (확인 절차 포함) | 확인 창에서 취소하면 안 지워진다 |
| 6 | 입력값 검증 3종 | 아래 표대로 막힌다 |
| 7 | 선택 기능: 키워드 검색 | 활동명·장소로 걸러진다 |
| 8 | 선택 기능: 반응형 | 좁은 화면에서 세로로 쌓인다 |

## 입력값 검증

| 항목 | 규칙 | 어긋나면 |
|---|---|---|
| 활동명 | 필수 | 저장 막고 메시지 표시 |
| 날짜 | 미래 날짜 불가 | 저장 막고 메시지 표시 |
| 참여 인원 | 1 이상 정수 | 저장 막고 메시지 표시 |

## 데이터 구조

```
localStorage["activities"] = [
  { id, title, date, place, memberCount, memo, createdAt }
]
```

`id`는 저장 시각 기반으로 만든다. 삭제·수정 때 이 값으로 찾는다.

## 화면 구성

```
┌─────────────────────────────┐
│ 제목                         │
├─────────────────────────────┤
│ [활동 등록 폼]                │
│  활동명 / 날짜 / 장소         │
│  참여 인원 / 메모  [등록]     │
├─────────────────────────────┤
│ [검색창]                     │
├─────────────────────────────┤
│ [활동 목록] 최신순            │
│  · 활동명 (날짜)  [삭제]      │
│    장소 · N명                │
│    메모                      │
└─────────────────────────────┘
```
