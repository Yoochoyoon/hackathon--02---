# 2인 역할 분담과 시간표

작성 13:50. **제출 마감 16:40** (16:40~17:00은 총평, 이후 커밋 인정 안 됨).
남은 시간 170분.

## 역할

| | 담당 A | 담당 B |
|---|---|---|
| 주 담당 | `app.js` — 데이터·기능 로직 | `index.html` + `style.css` — 화면 |
| 겸임 | 테스트(검증 규칙 깨보기) | **기록**(`작업기록.md`) + 보고서 |
| 만지는 파일 | `app.js` | `index.html`, `style.css` |

**파일을 갈라 놓은 이유**: 3파일짜리 앱이라 같은 파일을 동시에 만지면 충돌 처리에
시간을 다 뺏긴다. A는 로직, B는 화면만 만진다. `index.html`에 폼·목록 자리만
B가 먼저 잡아두면 A는 그 안을 채우기만 하면 된다.

**기록을 B가 겸하는 이유**: 보고서 3장이 전체의 절반인데 "실제 입력한 문장 그대로"를
요구한다. 나중에 기억으로 복원하면 반드시 틀린다. 화면 작업은 중간에 끊어도 되므로
B가 프롬프트를 던질 때마다 원문을 바로 붙여 넣는다.

## 마디마다 지킬 것

- **기능 하나 되면 바로 커밋.** 몰아서 하지 않는다(명세 규칙)
- 커밋 메시지: `<기능명>: <무엇을 했는지>`
- **각자 자기 계정으로 커밋한다.** "팀원 전원의 커밋 기록"이 제출 요건이다
- 15:30에 구현이 밀렸으면 **선택 기능(검색)을 버린다.** 필수 3종 + 검증이 우선
