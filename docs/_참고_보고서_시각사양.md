# 보고서 시각 사양 (블로그 예시 사진 실물 기준)

출처: 「보고서 서식 공통적용 표준사항」 예시 이미지, 2026. 8. 5. 캡처본 확인.
앞서 정리한 `_참고_보고서표준서식.md` 는 **글꼴·크기 표**이고, 이 문서는 **눈에 보이는 배치**다.
"전문적인 느낌"은 아래 네 요소가 만든다.

## 위에서부터 순서대로

```
                                    ┌──────────┬──────────┐
①  우측 상단 분류 탭                 │ 간이보고서 │ 정책보고서 │   ← 2칸 표, 오른쪽 정렬
                                    └──────────┴──────────┘
                                      파란바탕     흰바탕
                                      흰 글자      검은 글자

②  제목 글상자          ┌────────────────────────────────────────┐
                        │          기 획 보 고 서 제 목            │  ← 색 바탕 전체 폭
                        └────────────────────────────────────────┘     가운데, 굵게, 큼

③  작성 정보                                      2026. 8. 5.  ○○○팀   ← 오른쪽 정렬
                        ────────────────────────────────────────       ← 가로줄

④  개요 블록            ──────────────────────────────────────
                        …… 현안사항 및 대책을 보고드림
                        ──────────────────────────────────────       ← 위아래 줄로 감쌈

⑤  본문                 □ 사업개요
                          ○ ……
                          ○ ……

                        □ 현안사항
                          ○ ……
                           - ……
                            ※ ……

⑥  꼬리말                            대통령 보고서                     ← 가운데
                                          4                          ← 쪽번호
```

## 각 요소 상세

| # | 요소 | 모양 | 비고 |
|---|---|---|---|
| ① | 분류 탭 | 1행 2칸 표, 오른쪽 정렬. 선택된 칸만 파란 바탕·흰 글자 | 문서 성격 표시 |
| ② | 제목 글상자 | 전체 폭 색 바탕 상자, 가운데 굵은 제목<br>연한 옥색 = 기획·검토 / 분홍(연주황) = 상황 / 흐린 파랑 = 행사 | **가장 눈에 띄는 요소** |
| ③ | 작성 정보 | 오른쪽 정렬 날짜·부서, 바로 아래 가로 실선 | |
| ④ | 개요 블록 | 위·아래 가로줄 사이에 한두 줄 요지 | "…를 보고드림" 투 |
| ⑤ | 본문 | `□` → `○` → `-` → `※` | `-` 는 짧은 하이픈 |
| ⑥ | 꼬리말 | 가운데 문서 종류명 + 쪽번호 | |

## 우리 보고서에 옮길 때

- ①의 탭 문구는 과제에 맞게 — 예: `결과보고서` / `해커톤`
- ②의 바탕색은 결과 보고이므로 **연한 옥색** 계열
- ④의 개요는 "…동아리 활동 기록 관리 웹앱 개발 결과를 보고드림" 한 줄
- ⑥ 꼬리말은 `2026 해커톤` 정도

## 앞서 잘못 짚었던 것

텍스트 표에 `A4 횡`이 있어 가로 용지로 봤는데, **예시 사진은 세로다.**
표 문구만 보고 단정한 것이 틀렸다. 사진 기준으로 **세로**를 쓴다.
