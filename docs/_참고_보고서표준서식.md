## 지금 우리 보고서와 다른 점

| 항목 | 표준 | 지금 |
|---|---|---|
| **문서제목 글상자** | 색 바탕 + 테두리 상자 안에 22p 제목 | 없음 — 평범한 제목 |
| **개요 글상자** | 위 실선·아래 겹줄로 감싼 요지 상자 | 없음 |
| 본문 크기 | 15p | 11p |
| 용지 방향 | A4 가로 | 세로 |
| 줄간격 | 160% | 170% |

**"전문적인 느낌"의 정체는 앞의 두 상자다.** 제목이 색 바탕 상자 안에 들어가고,
그 아래 개요 상자가 한 번 더 감싸는 구조가 관공서 보고서의 첫인상을 만든다.

## 적용 시 판단할 것

- **용지 가로(A4 횡)**는 이번 과제 보고서(2~4쪽, PDF 제출)에 그대로 쓰기엔 과하다.
  세로를 유지하고 나머지 서식만 따르는 편이 안전하다.
- **바탕색**은 보고서 성격에 따라 다르다. 이번 것은 결과 보고이므로
  기획·검토 계열(연한옥색)에 가깝다.
